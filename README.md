# 🏥 Healthcare Analysis Dashboard

## 📌 Project Overview

This project is an interactive Healthcare Analysis Dashboard developed using Microsoft Power BI.

The dashboard provides a comprehensive view of healthcare data, allowing users to explore patient demographics, medical conditions, hospital performance, healthcare costs, insurance coverage, medication patterns, and admission trends.

The project demonstrates how data analytics and visualization can be used to transform healthcare data into meaningful business and operational insights.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze patient demographics and healthcare conditions.
- Examine hospital performance and patient outcomes.
- Analyze healthcare billing and insurance coverage.
- Identify patterns in medications and medical conditions.
- Examine admission patterns and patient distribution.
- Provide interactive visualizations for healthcare decision-making.
- Generate insights and recommendations from the analysis.
